Quick NPC Answer

Stop treating every character as the same type of page. Check mentors for hobby unlocks, merchants for inventory and services, townsfolk for friendship, and special NPCs for dynamic routes.

If you only need a location, open the map first. If you need a gift route, use a tracker.

Gifting Mechanics

  • Pick one NPC target before testing rare gifts.
  • Record reaction, gift type, and check date.
  • Use low-cost tests before spending event items.

Finding NPCs

  • Use map tracking when an NPC icon is available.
  • Check shop schedule first for shopkeepers.
  • For dynamic NPCs, treat location as time-sensitive.
